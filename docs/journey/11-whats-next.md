# 11. What's next

[← Release](10-release.md) · [Back to README](../../README.md)

NorthStar is released, but it is not finished. A planner that someone uses every day is never finished.

## Near term

- **Google Play, public.** After the closed test, the app goes public on Google Play.
- **The promo video**, linked from the landing page and from [chapter 10](10-release.md#promo-video).
- **More feedback rounds** with my mum and the first outside users, same rule as before: every bug found gets fixed.
- **Signed desktop builds**, so Windows and Mac downloads open without warnings.

## Ideas on the list

- **Editing Outlook events directly** from NorthStar, not only Google ones. Calendar links will always stay as the reliable fallback.
- **Backup straight to your own cloud drive**, next to today's "Export all my data" file.
- **More widgets and more widget options**, like text size and compact or detailed layouts.
- **Sharing** a page or a notebook with someone, carefully, so that private notes stay private.

## Things I would do the same again

- Plan for two days before writing any code.
- Ship to one real user in the first week.
- Make the app honest about sync.
- Use invented demo data for every public picture, from the start.

## Things I would do differently

- Decide on **one ink engine** from day one.
- Write down the *why* behind every design rule, so changing course (like Glass) is easier.
- Test on **every real device with every kind of pen** much earlier, not only the iPad.

Thank you for reading. If you want to try NorthStar, the links are in the [Download](../../README.md#download) section.
