# 11. What's next

[← Release](10-release.md) · [Back to README](../../README.md)

NorthStar is released, but it isn't finished. A planner that someone uses every day never is.

## Near term

First, Google Play. When the closed test is over, the app goes public there.

The promo video is next. It will be linked from the landing page and from [chapter 10](10-release.md#promo-video).

There will be more feedback rounds with my mum and the first outside users. Same rule as before: every bug found gets fixed.

I also want signed desktop builds, so the Windows and Mac downloads open without warnings.

## Ideas on the list

I'd like to edit Outlook events directly from NorthStar, the way it already works for Google ones. Calendar links will always stay as the reliable fallback.

Backup straight to your own cloud drive, next to today's "Export all my data" file.

More widgets and more widget options, like text size and compact or detailed layouts.

And sharing a page or a notebook with someone. Carefully, so that private notes stay private.

## What I would do the same again

Plan for two days before writing any code. Give it to one real user in the first week. Make the app honest about sync. Use invented demo data for every public picture, from the start.

## What I would do differently

I would decide on one ink engine from day one.

I would write down the why behind every design rule, so that changing course (like with Glass) is easier.

And I would test on every real device with every kind of pen much earlier. For too long I only tested on the iPad.

Thank you for reading. If you want to try NorthStar, the links are in the [Download](../../README.md#download) section.
